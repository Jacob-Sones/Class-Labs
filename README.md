# Class-Labs

Selected projects from my programming courses at Northwest Vista College, including Programming II (Java, Spring 2026) and Introduction to Programming (C++, Fall 2025). Each project folder has its own README explaining what the project does and the skills it demonstrates.

The Java projects focus on object-oriented design. They use inheritance, abstract classes, interfaces, and polymorphism to build larger programs made of classes that work together. Several projects apply design patterns, including the Observer and State patterns in the Natural Disaster Tracking System and the Chain of Responsibility pattern in the Support Ticket System. Exception handling and input validation are used throughout to keep programs stable when given bad data. The Bank Account System was a group project, and its README lists each team member's contributions.

The C++ projects cover the foundations of programming, including classes and encapsulation, vectors, user-defined functions, pass-by-reference, sorting, and input validation. Most are organized into separate header and implementation files. The Number Analyzer uses trial division to find the prime factors of a number.

Java projects were built in IntelliJ IDEA and use JDK 25 or newer. C++ projects were built in Xcode and can be compiled with g++.
