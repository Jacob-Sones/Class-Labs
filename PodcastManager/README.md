C++ project from Introduction to Programming (Fall 2025). A menu-driven program that manages a list of podcasts, letting you add, display, search, and sort them.

- Podcast class: stores host name, title, genre, duration, and release year with getters and setters
- HelperFunctions: validates number and text input, adds podcasts, displays the full list, and searches by title
- sortByDuration: custom comparison function used with sort() to order podcasts by length
- main.cpp: stores podcasts in a vector of objects and runs the menu loop
