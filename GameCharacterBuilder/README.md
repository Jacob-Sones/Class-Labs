C++ project from Introduction to Programming (Fall 2025). Creates two game characters and lets you view and edit their stats through a menu.

- gameCharacter class: stores name, character class, HP, and hit points as private data with getters and setters
- helperFunctions: validates number ranges, collects names and classes, and runs the display and edit-stats menus
- runStatsMenuChoice: uses pass-by-reference to update the selected character's stats
- main.cpp: creates both characters, collects their starting stats, and runs the menu loop
