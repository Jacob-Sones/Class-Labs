C++ extra credit project from Introduction to Programming (Fall 2025). Analyzes any whole number from 1 to 10,000.

- All factors: loops through every number up to the input and prints the ones that divide evenly
- Prime factors: uses trial division, dividing by the smallest factor and repeating until the number reaches 1
- Square and square root: shows both results to two decimal places
- Input validation: rejects letters, out-of-range numbers, and invalid menu choices
